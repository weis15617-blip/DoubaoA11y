# 回车键操作选项的来源与验收

功能参考维护者提供的 `DoubaoA11y-2.0.1-源码.zip` 中 `ConfigSpec.kt`、`VirtualKeys.kt` 的回车键选项，按主线现有的原生空格、删除处理路径分项引入。源码包内保留本项目 GPL-3.0 许可证；本次沿用该许可证，不包含其中的音效、词库或其他功能。源码包没有 Git 历史，贡献者姓名与原始提交待维护者补充，不虚构作者信息。

范围：

- 新增 `nativeEnter`，默认关闭，只在快速输入或关闭触摸浏览、触摸直接交给键盘时生效。
- 新增 `enterHoldMs`，默认 1 秒、可选 0.5 到 5 秒；抬手输入停留在“回车”“发送”键时复用主线长按注入路径。
- 标准输入继续由读屏双击操作；模块关闭或读屏关闭时沿用原来的停用判断。
- 原生空格、删除与候选导航保持各自原有路径；未引入全屏模式或自动发送兜底。

实机状态：未实机验证。执行清单时须记录手机、Android/ROM、豆包和读屏版本，以及输入方式、触摸浏览、快速输入和三个原生键开关。

验收：

1. 在豆包 1.5.4、1.5.5 分别检查普通回车与“回车键发送消息”场景，短触抬手只触发一次。
2. 抬手输入中验证 0.5、1、5 秒停留，移开或取消后不重复输入、不残留按下状态。
3. 开启原生回车后，触摸直接交给键盘的整串按下、移动、抬起交给豆包；行为与豆包原生一致。
4. 标准输入双击不受新停留时间影响；总开关关闭、读屏关闭时无额外接管。
5. 回归原生空格语音撤回、原生删除、候选切换及空格上屏，确认没有交叉影响。

编译与静态检查：使用 JDK 21.0.10、Android SDK platform 35 执行 ` .\gradlew.bat assembleRelease ` 成功（含 release lint 检查）；Git 差异空白检查通过，两份使用说明内容一致并保留 UTF-8 BOM。仅完成编译和静态检查，未实机验证。
