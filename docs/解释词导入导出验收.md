# 原解释词导入与导出

按用户最终要求，保留原内置词库及原朗读格式，没有引入独立版本的新词表，也没有调用当前读屏的私有词库。CharWords.kt 与 CharWordsData.kt 相对基线 0be0303 无差异。

入口：自定义解释词页面顶部“导入、导出解释词”。可导入 TXT/TSV、导出自定义词条，或导出全部内置词条与自定义覆盖。

文件格式为 UTF-8，每行“汉字 + 制表符 + 解释词”，例如 `高<TAB>提高`，TAB 指实际制表符。原模块会补成“高，提高的高”，不要填入“提高的高”完整短语。导出保留 UTF-8 BOM。文件上限 1 MiB、200000 字符；单条解释词 1 到 256 字符，拒绝控制字符、重复字、无效编码和无效条目。

导入只修改自定义覆盖。全部检查通过后展示覆盖数量，可选择合并或替换自定义；取消不写入。替换自定义不会删除内置词条，空文件选择替换时明确提示将清空自定义。保存失败尝试恢复原值，确认期间词条已变化则要求重新导入。
