## 已实现范围

- 默认仍为抬手输入与读屏播报。设置中显式选择“全屏输入”后，底部键盘保留，上半屏增加透明手势区。
- 19 个可配置槽位：单指单击、双击、四方向滑动，双指双击、四方向滑动，单指和双指各四方向拖动。拖动默认关闭；直接触摸下双指双击需要两次双指点按。
- 编辑轮盘支持增删、排序；上下滑切换、双击执行。选区操作时展开剪切、复制、删除和取消选择。迁移只补缺省，不覆盖用户定制。
- 字符、行、句、段移动及扩选，边界跳转、朗读、字数统计等；密码输入框不抽取整段内容供编辑朗读。
- 天坦、解说复用区域穿透接口，实际收到触摸就按触摸处理，仍收到悬停则按悬停处理。保益、点明、TalkBack、三星 TalkBack 和 sandfly 保留全局触摸浏览，通过悬停及无障碍点击/滚动动作补偿；用户自己关闭触摸浏览时走直接触摸。
- 独立语音库在模块自身进程运行，可选引擎、发音人、语速、语调、0–100% 音量及媒体/无障碍音量通道。未就绪、初始化超时或同步播放失败时，当前提示回退主线读屏事件；异步播放错误标记失败，使后续提示回退读屏。
- 配置与语音 IPC 通过 Provider 传递，校验真实 Binder UID，只允许本模块和目标输入法。反向写入只允许合法 `typeMode`，不能从输入法开启日志等其他设置。
- 模块关闭、读屏关闭、切回原输入模式、窗口收起和锁屏时撤销全屏、停止轮盘查询及模块朗读。不隐藏输入法节点树，不周期调用全局读屏 interrupt。
- 发送只调用一个匹配签名的豆包原生入口，调用后不会继续尝试其他发送方式，也不会依据字数盲删内容。语音手势与实际录音状态同步，开始录音前停止模块 TTS。

## 明确限制

- 所有读屏与豆包兼容性均待实机验证。19 个槽位是可配置能力，**不代表触摸浏览开启时各家读屏都会把所有双指/拖动手势交给输入法**；实际可达动作由读屏分发决定。
- 独立 TTS 接管模块产生的提示，不屏蔽宿主应用的文字/选区事件，可能听到宿主应用读屏提示。这样保留读屏功能，避免为了静音而使界面不可操作。
- 已入队的语句若在 TTS 引擎内部异步失败，当前句不能保证追回；后续语句先回退读屏，冷却后可重试。不能把编译通过说成语音回退实机通过。
- Provider 不可访问、模块未安装或被系统限制后台启动时，独立语音回退读屏，配置继续使用已保存副本。LSPosed 与 LSPatch 两种安装方式都必须验证。
- 原生发送方法成功返回只表示已经请求豆包执行动作，不证明应用或服务器已经发送成功；“发送并收起”是用户明确选定的动作。
- 未将未确认的保益广播、点明服务请求当成“触摸浏览已经关闭”；当前版本不修改全局触摸浏览状态。
