# 上半屏手势功能与操作完整说明报告（用户视角）

这份文档从实际使用者的角度，完整梳理了目前“上半屏手势”的所有开关、手势操作、编辑菜单变化规律以及全部可设置的功能。你可以直接在对应条目后面批注或修改。

---

## 一、什么是“上半屏手势”

开启“上半屏手势”后，手机屏幕在弹出豆包键盘时分为上下两部分：

- **下半屏（键盘区）**：保持原有的豆包键盘操作不变（手指摸到哪个键就读哪个键，抬手输入；停留在删除键上连续删除，停留在空格键上开始语音输入）。此外，在键盘区也可以直接使用**双指手势**（如双指双击开始语音输入）。
- **上半屏（手势区）**：键盘最顶边（工具栏、候选栏）往上的整片屏幕变成透明的手势操作区。在这片区域里做单指、双指的点按、滑动或按住拖动，就能直接移动光标、选候选字、选择和编辑文字、朗读输入框内容或开始语音，不需要再去键盘里找小按钮。
- **自动让路**：当你打开豆包的“菜单”“剪贴板”“常用语”或“定制工具栏”时，上半屏手势区会自动暂时收起，把屏幕交还给读屏软件正常左右滑动浏览；关掉这些界面回到键盘后，上半屏手势自动恢复。

## 二、怎么开启和关闭“上半屏手势”

目前有 3 种方式可以开启或关闭：

1. **在模块设置页里开关**
   打开“豆包输入法无障碍” → 进入 **“上半屏操作与手势”** → 页面最上方第一项就是 **“上半屏手势”** 开关。
2. **在键盘工具栏上点按钮一键切换**
   - 先在豆包键盘点 **“菜单 → 定制工具栏”**，点底部的 **“下一页”** 翻到第 2 页，在 **“发送”右侧** 找到 **“上半屏手势”** 方块，双击将它添加到工具栏，再点顶部“完成”。
   - 之后键盘上方的工具栏里就会出现 **“上半屏”** 按钮（读屏读作 **“开启上半屏手势”** 或 **“关闭上半屏手势”**），随时双击即可开启或关闭。
3. **用手势切换**
   你可以把任意一个不常用的手势（例如“双指下滑”）设置为 **“关闭上半屏手势”** 或 **“临时关闭上半屏手势”**，在屏幕上做一下这个手势就能直接切回普通半屏模式。

## 三、出厂默认手势一览（开箱即用的操作方式）

以下是在没有改过设置时的默认手势功能。所有手势都可以在“上半屏操作与手势”里自由改成你喜欢的动作。

### 1. 平时（输入框里没有正在拼写的候选字时）

| 手势操作 | 默认功能 | 实际效果说明 |
| :--- | :--- | :--- |
| **单指单击** | **朗读编辑框文字** | 读出当前输入框里已经写好的文字；如果输入框是空的，会提示“编辑框为空”。 |
| **单指双击** | **执行当前编辑菜单** | 执行你用上下滑动选中的那个编辑菜单项。刚弹出键盘或刚打完字时，只要输入框里有字，默认停在“双击跳转行首行尾”，所以**直接单指双击就能在行首和行尾之间来回跳转**；如果输入框是空的，默认停在“粘贴”，**直接单指双击就能粘贴**。 |
| **单指左滑** | **上一个字符或候选词** | 光标往左移动一个字并读出该字；已经在最开头还继续左滑时，读出“共X个字 + 输入框全文”（空框读“编辑框为空”）。 |
| **单指右滑** | **下一个字符或候选词** | 光标往右移动一个字并读出该字；已经在最末尾还继续右滑时，同样读出“共X个字 + 输入框全文”（空框读“编辑框为空”）。 |
| **单指上滑** | **上一个编辑菜单** | 在编辑菜单列表里往上切一项，并读出这一项的名字（如“收起键盘”“清空文本”“粘贴”等）。 |
| **单指下滑** | **下一个编辑菜单** | 在编辑菜单列表里往下切一项，并读出这一项的名字（如“全选”“选择文本”“粘贴”等）。 |
| **双指单击** | 未指定 | 默认未绑定动作，可在设置里自行分配。若“双指双击”设为未指定，双指单击抬手即零延迟执行；若同时绑定了“双指双击”，会等待一个双指双击判定窗口确认不是双击后再执行。在下半屏键盘区双指单击也一样有效。 |
| **双指双击** | **语音输入** | 第一次双指双击开始说话录音；说完了再双指双击一次就结束录音并把识别出的文字放进输入框（不用一直按着屏幕）。在下半屏键盘区双指双击也一样有效。 |
| **双指上/下/左/右滑** | 未指定 | 默认未绑定动作，可在设置里自行分配（例如设成“上一行/下一行”“上一句/下一句”“执行发送”等）。 |
| **单指/双指四个方向拖动** | 未指定 | 默认关闭拖动手势；开启后可绑定动作（例如按住往左拖动连续移光标或连续删字）。 |

---

### 2. 正在打字时（候选栏里出现了候选字词）

当你刚刚在下半屏键盘上打了拼音或写了字、候选栏里正在显示候选词时（并且不在选择文本状态、也没有刚刚上下滑切过编辑菜单），上半屏的单指手势会自动优先用来选字上屏：

| 正在打字时的手势 | 实际效果说明 |
| :--- | :--- |
| **单指左滑** | **切换到上一个候选词**，并立刻读出该候选词（单字直接读“某某的某”，多字词读完词再逐字解释）。翻到后续页后向左滑动可无缝回到上一页；到第一个时提示“已到头”。 |
| **单指右滑** | **切换到下一个候选词**，并立刻读出该候选词；滑到当前最后一项时会自动加载更多候选词。 |
| **单指上滑** | **清空当前候选栏**（把刚打到一半的拼音清掉，不上屏），并提示“候选栏已清空”。 |
| **单指下滑** | **把当前选中的候选词直接上屏**（写进输入框）。 |
| **单指单击 / 单指双击** | **把当前选中的候选词直接上屏**（如果你刚刚用上下滑切换过编辑菜单，2 秒内双击会优先执行你刚选的编辑菜单，不会误上屏候选词）。 |

> 注：如果候选栏里只是因为移动了光标而弹出的“联想词”，不会抢占你的左右滑手势，单指左滑、右滑依然是正常移动光标。

## 四、编辑菜单的三种状态（单指上下滑切换、单指双击执行）

编辑菜单会根据当前输入框的状态**自动变换内容**，省去没必要的选项：

### 状态 1：当输入框是空的（里面一个字都没有）
此时你不需要全选、复制或清空，所以菜单里只保留最常用的 **2 项**：
1. **粘贴**（默认停在这一项：面对空输入框，直接**单指双击**就能把剪贴板里的文字贴进来）
2. **收起键盘**

一旦输入框里有了文字（不管是打字、语音输入、粘贴还是应用自带的内容），菜单会立刻自动切回下面的完整菜单。

### 状态 2：当输入框里有文字时（完整编辑菜单）
出厂默认有 **6 项**（你可以在“上半屏操作与手势 → 自定义编辑菜单”里随便改顺序、删掉不用的项，或者添加其他功能）：
1. **双击跳转行首行尾**（在菜单里叫“默认”：刚弹出键盘或每次打完字、做完一次粘贴后，都会自动回到这一项。此时直接**单指双击**，光标在行尾就跳到行首，不在行尾就跳到行尾）
2. **全选**（双击后把输入框里的字全部选中，提示“全选，共X个字”，并自动进入下面的“状态 3”）
3. **选择文本**（双击后从当前光标位置开始选字，提示“开始选择”，并自动进入下面的“状态 3”）
4. **粘贴**（双击把剪贴板文字粘贴到光标处，粘贴完自动回到第 1 项）
5. **清空文本**（双击把输入框里的文字全部清空）
6. **收起键盘**（双击把键盘收起来）

### 状态 3：当已经选中了文字时（执行了“全选”或“选择文本”之后）
一旦进入选字状态：
- **怎样扩大或缩小选中的范围**：如果你点的是“选择文本”，这时在屏幕上做**单指左滑、单指右滑**（或者你绑定的上一行、下一行、上一句、下一句、上一段、下一段、跳到行首/行尾/开头/结尾手势），就不会只是移动光标，而是**从起点开始一格一格（或一句一句、一段一段、一行一行）扩大或缩小选中的文字范围**，并按“先念字、再念已选中 / 已取消”的规则播报本次增量（在解说/保益/点明读屏下，单字扩缩选交给读屏即时播报，按句/段/行扩缩选由模块播报“xxx已选中 / xxx已取消”；天坦全屏手势下由模块统一零延迟播报）。
- **此时的编辑菜单自动变成 4 项专用操作**（不用在设置里配，选完字自动出现）：
  1. **剪切**（默认停在第 1 项：全选或选好文字后，直接单指双击就能剪切；也可以下滑切到“复制”再双击）
  2. **复制**
  3. **删除文本**（把选中的这一段删掉）
  4. **取消选择**（不选了，退出选择模式）
- 执行完“剪切”“复制”“删除文本”或“取消选择”，或者你在下半屏键盘上打了新字、按了删除键、收起键盘，就会自动退出选择模式，恢复到平时的编辑菜单。

## 五、全部可分配的功能清单（共 34 项）

在 **“上半屏操作与手势”** 中，你可以给 **20 个手势** 中的任意一个绑定以下 **34 项功能**（除了前 1 项“未指定”和 3 项编辑菜单自身切换功能外，其余 30 项也都可以添加进“自定义编辑菜单”里）：

### （一）光标移动与跳转（12 项）
1. **上一个字符或候选词**：打字有候选时切到上一个候选词；平时把光标往左移一个字（选字模式下往左扩选一个字）。
2. **下一个字符或候选词**：打字有候选时切到下一个候选词；平时把光标往右移一个字（选字模式下往右扩选一个字）。
3. **上一行**：光标移到上一行，并读出上一行的内容（选字模式下往上扩选一行）。
4. **下一行**：光标移到下一行，并读出下一行的内容（选字模式下往下扩选一行）。
5. **上一句**：按你设置的句子标点（如句号、逗号、问号、感叹号、分号、换行等），把光标跳到上一句，并读出这一句（选字模式下按句往前扩选）。会避开“3.14”这种小数点。
6. **下一句**：按句子标点跳到下一句，并读出这一句（选字模式下按句往后扩选）。
7. **上一段**：按换行符跳到上一段，并读出上一段文字（选字模式下按段往前扩选）。
8. **下一段**：按换行符跳到下一段，并读出下一段文字（选字模式下按段往后扩选）。
9. **光标跳到行首**：把光标跳到当前这一行的最开头，提示“行首”（选字模式下从当前位置一直选到行首）。
10. **光标跳到行尾**：把光标跳到当前这一行的最末尾，提示“行尾”（选字模式下从当前位置一直选到行尾）。
11. **光标跳到开头**：把光标跳到整篇文字的最开头，提示“已到开头”（选字模式下一直选到全文开头）。
12. **光标跳到结尾**：把光标跳到整篇文字的最末尾，提示“已到结尾”（选字模式下一直选到全文结尾）。

### （二）编辑菜单与行首行尾跳转（4 项）
13. **上一个编辑菜单**：往上切换编辑菜单里的选项并读出名字（默认绑在“单指上滑”）。
14. **下一个编辑菜单**：往下切换编辑菜单里的选项并读出名字（默认绑在“单指下滑”）。
15. **执行当前编辑菜单**：执行当前停留在的编辑菜单项（默认绑在“单指双击”）。
16. **双击跳转行首行尾**：如果当前光标不在末尾，就跳到末尾并读“已到结尾”；如果已经在末尾，就跳到开头并读“已到开头”。

### （三）选择、修改与删除文字（6 项）
17. **选择文本**：进入或退出手动选字模式。进入时提示“开始选择”，随后用左右滑或句/段/行手势选择文字范围，编辑菜单自动变为“剪切 / 复制 / 删除文本 / 取消选择”。
18. **全选**：一次性选中输入框里的全部文字，提示“全选，共X个字”，编辑菜单同样自动变为“剪切 / 复制 / 删除文本 / 取消选择”。
19. **删除**：删除光标左边的一个字，按“先字后状态”读出“[被删字]已删除”（如果正在选字模式下，则直接删掉选中的整段文字，6 字以内读“[选中文字]已删除”，超过 6 字读“X个字已删除”）。
20. **向后删除**：删除光标右边的一个字，读出“[被删字]已删除”（到结尾提示“已到结尾”，空框提示“编辑框为空”）。
21. **清空文本**：把当前输入框里的所有文字一次性全部删空，提示“X个字已清空”（空框提示“编辑框为空”）。
22. **粘贴**：把系统剪贴板里的文字粘贴到当前光标位置，通过前后文本对比提取真实插入的内容，读出“[粘贴文字]已粘贴”（超过 24 字读“[前24字]等X个字已粘贴”）。

### （四）朗读与字数查看（4 项）
23. **朗读编辑框文字**：从头朗读当前输入框里的全部文字（默认绑在“单指单击”）；空框提示“编辑框为空”。
24. **朗读当前行**：只朗读光标所在这一行的文字；如果是空行会提示“空行”。
25. **朗读选中文字**：朗读当前已经选中的那段文字，读作“[选中文字]，已选中”；选中的全是空白提示“选中的是空白”；当前没有选中文字时自动改为朗读当前行。
26. **字符统计**：读出当前输入框一共有多少个字、不含空格有多少个字；如果正选中了一部分文字，会读出“选中 X 个字，全文 Y 个字”；空框提示“编辑框为空”。

### （五）发送、语音与键盘控制（7 项）
27. **语音输入**：开始或结束豆包语音输入（默认绑在“双指双击”）。第一次触发相当于按住空格开始说话，再触发一次相当于松开空格结束说话并上屏。
28. **智能整理**：直接触发豆包菜单内的“智能整理”功能（等同于点击菜单里的“智能整理”）。可绑定到任意手势，也可以添加进“自定义编辑菜单”。
29. **执行发送**：直接触发豆包输入法的发送功能（把输入框里的消息发出去，键盘保持展开）。
30. **发送并收起键盘**：把消息发送出去，同时自动把键盘收起来。
31. **收起键盘**：把豆包键盘收起。
32. **临时关闭上半屏手势**：不收起键盘，只在当前这一次把上半屏手势关掉、退回普通半屏键盘（方便你临时点一下屏幕上半部分的应用按钮）；等下次键盘收起再重新弹出时，会自动恢复上半屏手势。
33. **关闭上半屏手势**：直接把“上半屏手势”总开关关掉（永久生效，直到你再次在工具栏或设置里打开）。

### （六）不绑定动作（1 项）
34. **未指定**：让这个手势不执行任何操作。如果把“单指双击”设为“未指定”，那么“单指单击”不论绑定什么动作都不需要等待区分双击，抬手瞬间零延迟执行。

## 六、可设置的 20 个手势位置清单

在“上半屏操作与手势”页面中，共有以下 20 个手势可以分别设置动作：

### 1. 单指手势（6 个）
1. **单指单击**（出厂默认：朗读编辑框文字）
2. **单指双击**（出厂默认：执行当前编辑菜单）
3. **单指左滑**（出厂默认：上一个字符或候选词）
4. **单指右滑**（出厂默认：下一个字符或候选词）
5. **单指上滑**（出厂默认：上一个编辑菜单）
6. **单指下滑**（出厂默认：下一个编辑菜单）

### 2. 双指手势（6 个，上半屏和下半屏键盘区均可触发）
7. **双指单击**（出厂默认：未指定）
8. **双指双击**（出厂默认：语音输入）
9. **双指左滑**（出厂默认：未指定）
10. **双指右滑**（出厂默认：未指定）
11. **双指上滑**（出厂默认：未指定）
12. **双指下滑**（出厂默认：未指定）

### 3. 拖动手势（8 个，需先打开“启用拖动手势”开关）
> **怎么用拖动手势**：手指在屏幕上往某个方向滑一下之后**不要抬手**，继续按住往那个方向拖，就会每隔一段固定时间（默认 0.3 秒）反复执行一次该方向的动作，抬手即停。非常适合用来**连续快速移动光标**或**连续删字**。开启拖动手势且该方向绑定了拖动动作时，滑动与拖动自动互斥：快速滑完抬手只执行普通滑动，按住进入拖动后只执行拖动手势，不会先触发一次普通滑动。

13. **单指向左拖动**（出厂默认：未指定）
14. **单指向右拖动**（出厂默认：未指定）
15. **单指向上拖动**（出厂默认：未指定）
16. **单指向下拖动**（出厂默认：未指定）

## 七、“上半屏操作与手势”设置页从上到下全部设置项汇总

当你打开“豆包输入法无障碍 → 上半屏操作与手势”时，页面从上到下依次是：

1. **上半屏手势**（开关，默认关）：开启或关闭上半屏手势模式。
2. **自定义编辑菜单**（列表 +“添加一项”按钮）：
   - 列表里展示当前编辑菜单的每一项（默认 6 项：双击跳转行首行尾、全选、选择文本、粘贴、清空文本、收起键盘）；

3. **手势灵敏度**（列表选择，默认“2（中）”）：
   - 可选：**1（低）**（滑动距离要长一点、防误触）、**2（中）**（标准手感）、**3（高）**（轻轻一划就触发，双击判定也最快）。
4. **单指**（6 个单指手势的动作选择按钮）。
5. **双指**（6 个双指手势的动作选择按钮）。
6. **拖动**：
   - **启用拖动手势**（开关，默认关）；
   - **拖动重复间隔**（列表选择，默认 **0.3 秒**，可选 0.1 秒、0.2 秒、0.3 秒、0.4 秒、0.5 秒、0.6 秒、0.7 秒、0.8 秒）；
   - 8 个单指/双指拖动手势的动作选择按钮。
7. **候选与反馈**：

   - **移动光标时朗读字词**（开关，默认开）：开启后移动光标会读出跨过的字；如果你用的读屏软件自己已经会读光标移动的字、导致读了两遍，可以把这个开关关掉（到开头、到结尾的提示仍会保留）。
8. **按句移动光标**（“添加标点”按钮 + 标点列表）：
   - 用来决定“上一句”“下一句”遇到哪些符号算作一句话的结尾；
   - 默认包含 **11 个分隔符**：英文句号 `.`、英文逗号 `,`、英文分号 `;`、英文问号 `?`、英文感叹号 `!`、中文句号 `。`、中文逗号 `，`、中文分号 `；`、中文问号 `？`、中文感叹号 `！` 以及 **`换行`**；
   - **点击列表里的某个标点**：直接删掉该标点；
   - **点击“添加标点”**：输入一个新的标点符号（或输入“换行”）加进列表。
9. **恢复默认**（按钮，带确认弹窗）：点击并确认后，将上半屏手势、自定义编辑菜单和按句移动光标的标点全部恢复为出厂默认设置。

## 八、每个操作具体会触发的朗读内容汇总

下面把每个手势动作在不同情况下**实际读出来的原话**逐一列出（引号内为实际朗读的语音文本，`X`/`Y` 代表实际字数，`[...]` 代表实际文字内容），方便你逐条核对或修改朗读词：

### （〇）统一朗读规则与多读屏防冲突策略

- **“先念字，再念已xx”原则**：所有涉及文字的选择、取消、删除、复制、剪切、粘贴、清空提示，均先播报被操作的文字（或字数），再播报状态（如 `“好已选中”`、`“好已删除”`、`“你好已复制”`、`“10个字已清空”`）；单个标点与空白统一转为中文名称（如 `“逗号”`、`“空格”`、`“换行”`）。
- **天坦读屏（`com.android.tback`）**：开启上半屏手势时，模块自动通知天坦屏蔽编辑框的文本变化与选区变化播报，由模块 **0 延迟**统一播报所有手势反馈以及打字/删除回显；收起键盘、打开工具栏面板、切回半屏或熄屏时自动恢复天坦原生播报。
- **解说 / 保益 / 点明读屏**：采用分工协作策略（方案 A）：
  - **单字光标移动、单字扩选/缩选**：直接交给读屏即时播报，正常逐字滑动不抢麦；仅在极速连滑（相邻间隔 ≤ 150ms、落入读屏去抖窗口可能漏念）停手后补念最后一格，以及左移到达开头第 0 格（读屏无前字可念）时补念第 1 个字。
  - **按句 / 按段 / 按行移动与扩缩选、边界、全选、删除、复制、剪切、粘贴、清空**：由模块在选区/文本更新后播报；其中“取消选择 / 选区归零 / 单字句段跳转”在解说下自动延后 140ms 覆盖，避免被解说的 100ms 单字文字解释反打断。
- **独立语音库模式**：不依赖读屏事件顺序，全部动作由模块即时播报。

### （一）打字有候选字词时的手势朗读

1. **单指左滑（上一个候选词） / 单指右滑（下一个候选词）**
   - **正常切换候选词**：
     - 单个字（有解释词）：**`“观看的看”`**
     - 单个字（无解释词或关闭了字词解释）：**`“看”`**
     - 多个字（开启了字词解释）：**`“高兴，提高的高，高兴的兴”`**
     - 多个字（关闭了字词解释）：**`“高兴”`**
   - **已经到第 1 个还继续左滑，或到最后 1 个且没有更多候选可加载**：
     - **`“已到头，[当前候选词读法]”`**（例如：**`“已到头，观看的看”`**）
2. **单指上滑（清空当前候选栏）**
   - **成功清空**：**`“候选栏已清空”`**
   - **当前没有候选或清空失败**：**`“现在没有候选”`** 或 **`“清空候选没成功”`**
3. **单指下滑 / 单指单击 / 单指双击（把当前候选词上屏）**
   - **成功上屏**：由读屏软件或模块回显（天坦全屏屏蔽生效或开启“独立语音库朗读上屏文字”时）直接读出上屏的字词
   - **上屏失败**：**`“候选没上屏”`**（或 **`“现在没有候选”`** / **`“没找到空格键”`**）

---

### （二）光标移动与跳转（12 项）的朗读

1. **上一个字符或候选词**（平时往左移 1 个字）
   - **有打字候选时**：同上，朗读切换到的候选词；到头读 **`“已到头，[当前候选词]”`**
   - **平时正常左移 1 个字**（开启“移动光标时朗读字词”时）：
     - 解说 / 保益 / 点明读屏：正常逐字左滑交由读屏直接朗读（极速连滑 ≤ 150ms 停手后补念最后一格；走到开头第 0 格时由模块补读第 1 个字）
     - 天坦全屏屏蔽或独立语音库：普通字读 **`“[跨过的那个字]”`**（如 **`“吃”`**），标点/空白读 **`“逗号”`**、**`“句号”`**、**`“空格”`**、**`“换行”`** 等符号中文名
   - **光标已经在最开头，还继续往左滑（到头边界）**：
     - 输入框有字时：**`“共X个字[输入框全文内容]”`**（例如：**`“共4个字吃饭了吗”`**）
     - 输入框是空的：**`“编辑框为空”`**
   - **在选择文本模式下往左滑（按字扩选/缩选）**：
     - 解说 / 保益 / 点明读屏：单字扩选/缩选直接交给读屏即时朗读（emoji 等多码元增量由模块补读 **`“[增量文字]已选中”`** / **`“[增量文字]已取消”`**）
     - 天坦全屏屏蔽或独立语音库：只读本次变化的增量，扩选读 **`“[字或符号名]已选中”`**，缩选读 **`“[字或符号名]已取消”`**
     - 恰好退回到选字起点（选中字数变回 0）：**`“取消选择”`**（解说下自动错开文字解释防打断）
     - 已经选到最开头还继续往左滑：未选任何字时读 **`“已到开头”`**；已有选中时读 **`“已选到开头，共X个字”`**

2. **下一个字符或候选词**（平时往右移 1 个字）
   - **有打字候选时**：同上，朗读切换到的候选词；到头读 **`“已到头，[当前候选词]”`**
   - **平时正常右移 1 个字**：
     - 解说 / 保益 / 点明读屏：交由读屏直接朗读（含走到最后一个字；极速连滑 ≤ 150ms 停手后补念最后一格）
     - 天坦全屏屏蔽或独立语音库：**`“[跨过的那个字或符号中文名]”`**
   - **光标已经在最末尾，还继续往右滑（到尾边界）**：
     - 输入框有字时：**`“共X个字[输入框全文内容]”`**（与开头边界保持一致）
     - 输入框是空的：**`“编辑框为空”`**
   - **在选择文本模式下往右滑（按字扩选/缩选）**：
     - 解说 / 保益 / 点明读屏：单字扩选/缩选交由读屏即时朗读（多码元增量由模块补读）
     - 天坦全屏屏蔽或独立语音库：扩选读 **`“[字或符号名]已选中”`**，缩选读 **`“[字或符号名]已取消”`**
     - 恰好退回到选字起点：**`“取消选择”`**
     - 已经选到最末尾还继续往右滑：未选任何字时读 **`“已到结尾”`**；已有选中时读 **`“已选到末尾，共X个字”`**

3. **上一行** / 4. **下一行**
   - **平时移动**：
     - 移到的那一行有文字：**`“[当前整行文字]”`**（超过 200 字读 **`“[前200字]，后面还有X个字”`**）
     - 移到的那一行没有文字：**`“空行”`**
   - **在选择文本模式下（按行扩选/缩选，所有读屏均由模块播报）**：
     - 扩选：**`“[新增选中的文字]已选中”`**（超过 24 字读 **`“[前24字]等X个字已选中”`**）
     - 缩选：**`“[取消选中的文字]已取消”`**（超过 24 字读 **`“[前24字]等X个字已取消”`**）

5. **上一句**
   - **平时移动**：直接朗读 **`“[移动到的这一句文字]”`**（超过 200 字读 **`“[前200字]，后面还有X个字”`**）
   - **已经到最开头还继续往上一句**：
     - 输入框有字：**`“共X个字[输入框全文内容]”`**
     - 输入框是空的：不读（若触发边界则读 **`“编辑框为空”`**）
   - **在选择文本模式下（按句往前扩选/缩选，所有读屏均由模块播报）**：
     - 扩选：**`“[新增的这一句]已选中”`**（超过 24 字读 **`“[前24字]等X个字已选中”`**）
     - 缩选：**`“[取消的这一句]已取消”`**（超过 24 字读 **`“[前24字]等X个字已取消”`**；直接缩回起点归零时同样念被取消的这一句 + `“已取消”`）
     - 到头：**`“已到开头”`**（未选字）或 **`“已选到开头，共X个字”`**（已有选中）

6. **下一句**
   - **平时移动**：直接朗读 **`“[移动到的这一句文字]”`**（超过 200 字读 **`“[前200字]，后面还有X个字”`**）
   - **已经到最末尾还继续往下一句**：
     - 输入框有字：**`“共X个字[输入框全文内容]”`**
   - **在选择文本模式下（按句往后扩选/缩选，所有读屏均由模块播报）**：同上（扩选 **`“[句]已选中”`** / 缩选 **`“[句]已取消”`** / 到尾 **`“已到结尾”`** 或 **`“已选到末尾，共X个字”`**）

7. **上一段**
   - **平时移动**：直接朗读 **`“[移动到的这一段文字]”`**（超过 200 字读 **`“[前200字]，后面还有X个字”`**）
   - **已经到最开头还继续往上一段**：**`“共X个字[输入框全文内容]”`**
   - **在选择文本模式下（按段往前扩选/缩选，所有读屏均由模块播报）**：同上（扩选 **`“[段]已选中”`** / 缩选 **`“[段]已取消”`** / 到头 **`“已到开头”`** 或 **`“已选到开头，共X个字”`**）

8. **下一段**
   - **平时移动**：直接朗读 **`“[移动到的这一段文字]”`**（超过 200 字读 **`“[前200字]，后面还有X个字”`**）
   - **已经到最末尾还继续往下一段**：**`“共X个字[输入框全文内容]”`**
   - **在选择文本模式下（按段往后扩选/缩选，所有读屏均由模块播报）**：同上（扩选 **`“[段]已选中”`** / 缩选 **`“[段]已取消”`** / 到尾 **`“已到结尾”`** 或 **`“已选到末尾，共X个字”`**）

9. **光标跳到行首**
   - 朗读：**`“行首”`**（使用独立语音库时，若当前行有字，随后会跟读当前行文字）

10. **光标跳到行尾**
    - 朗读：**`“行尾”`**（使用独立语音库时，若当前行有字，随后会跟读当前行文字）

11. **光标跳到开头**
    - 朗读：**`“已到开头”`**（使用独立语音库时，随后跟读第一行文字）

12. **光标跳到结尾**
    - 朗读：**`“已到结尾”`**（使用独立语音库时，随后跟读最后一行文字）

### （三）编辑菜单与行首行尾跳转（4 项）的朗读

13. **上一个编辑菜单** / 14. **下一个编辑菜单**
    - 直接朗读**切换到的菜单项名称**（不受“执行手势后朗读结果”开关影响，始终朗读）：
      - 输入框为空时：读 **`“粘贴”`** 或 **`“收起键盘”`**
      - 输入框有字时（默认 6 项）：依次读 **`“双击跳转行首行尾”`**、**`“全选”`**、**`“选择文本”`**、**`“粘贴”`**、**`“清空文本”`**、**`“收起键盘”`**（如果加了自定义项，就读自定义项的名字）
      - 选中文字后（4 项）：依次读 **`“剪切”`**、**`“复制”`**、**`“删除文本”`**、**`“取消选择”`**

15. **执行当前编辑菜单**
    - 本身不单独念名字，直接执行当前选中的那一项，并朗读**那一项对应的结果语音**。

16. **双击跳转行首行尾**（编辑菜单里的“默认”项）
    - 光标不在末尾、跳到末尾时：**`“已到结尾”`**
    - 光标已经在末尾、跳回开头时：**`“已到开头”`**

---

### （四）选择、修改与删除文字（6 项基础项 + 3 项选字后专用项）的朗读

17. **选择文本**
    - 平时执行（进入选择模式）：**`“开始选择”`**
    - 已经在选择模式中再次执行（退出选择模式）：
      - 原本已经选中有文字并收起选区：**`“已取消选择”`**（解说下自动延后 140ms，避免被单字文字解释打断）
      - 还没选任何字就直接退出：**`“退出选择”`**

18. **全选**
    - 成功选中全部文字：**`“全选，共X个字”`**
    - 输入框为空或当前输入框不支持全选：**`“当前编辑框不支持全选”`**

19. **删除**（选中文字后在菜单里叫 **删除文本**）
    - 平时删掉光标左边的 1 个字：**`“[被删字或符号中文名]已删除”`**（例如：**`“吃已删除”`**、**`“逗号已删除”`**、**`“空格已删除”`**、**`“换行已删除”`**）
    - 输入框是空的：**`“编辑框为空”`**；光标已在开头没字可删：**`“已到开头”`**；拿不到被删字符兜底读 **`“已删除”`**
    - 在选择模式下删掉选中的整段文字：
      - 6 字以内：**`“[选中文字]已删除”`**
      - 超过 6 字：**`“X个字已删除”`**
    - （注：天坦全屏屏蔽开启时，下半屏原生删除键的删除回显同样遵循上述“先字后已删除”格式。）

20. **向后删除**
    - 删掉光标右边的 1 个字：**`“[被删字或符号中文名]已删除”`**
    - 输入框是空的：**`“编辑框为空”`**；光标已在结尾没字可删：**`“已到结尾”`**；拿不到字符兜底读 **`“已删除”`**

21. **清空文本**
    - 输入框有字并成功清空：**`“X个字已清空”`**（未知字数读 **`“已清空”`**）
    - 输入框本来就是空的：**`“编辑框为空”`**

22. **粘贴**
    - 粘贴成功（通过前后文本对比提取本次真实插入内容，光标在文段中间粘贴也能准确朗读）：
      - 24 字以内：**`“[粘贴文字]已粘贴”`**
      - 超过 24 字：**`“[前24字]等X个字已粘贴”`**
    - 粘贴成功但无法识别差值：**`“已粘贴”`**
    - 剪贴板为空或当前输入框不支持粘贴：**`“当前编辑框不支持粘贴”`**

- **【选字后专用项 1】剪切**
  - 成功剪切：24 字以内读 **`“[剪切文字]已剪切”`**；超过 24 字读 **`“[前24字]等X个字已剪切”`**；拿不到文字读 **`“已剪切”`**
  - 失败时：**`“当前编辑框不支持剪切”`**
- **【选字后专用项 2】复制**
  - 成功复制：24 字以内读 **`“[复制文字]已复制”`**；超过 24 字读 **`“[前24字]等X个字已复制”`**；拿不到文字读 **`“已复制”`**
  - 没有选中文字时：**`“没有选中的文字”`**
  - 失败时：**`“当前编辑框不支持复制”`**
- **【选字后专用项 3】取消选择**
  - 原本有选中的文字并取消：**`“已取消选择”`**（解说下自动延后 140ms，避免被单字文字解释打断）
  - 还没选字就直接退出选择模式：**`“退出选择”`**

---

### （五）朗读与字数查看（4 项）的朗读

23. **朗读编辑框文字**
    - 输入框有文字（**无论多少字都全部完整朗读**，不截断；使用独立语音库时超长文本自动分段连续朗读）：**`“[输入框里的全部文字]”`**
    - 输入框是空的：**`“编辑框为空”`**

24. **朗读当前行**
    - 光标所在行有文字：**`“[当前行的全部文字]”`**
    - 光标所在行没有文字（或输入框为空）：**`“空行”`**

25. **朗读选中文字**
    - 当前有选中的文字：**`“[选中的文字（最多前 200 个字）]，已选中”`**
    - 选中的全是空格/空白：**`“选中的是空白”`**
    - 当前没有选中文字：自动改为朗读当前行（有字读 **`“[当前行文字]”`**，空行读 **`“空行”`**）

26. **字符统计**
    - 平时（未选中文字）：**`“共 X 个字，不含空格 Y 个”`**
    - 正在选中一段文字时：**`“选中 X 个字，全文 Y 个字”`**
    - 输入框是空的：**`“编辑框为空”`**

---

### （六）发送、语音与键盘控制（7 项）的朗读

27. **语音输入**
    - 第一次触发（开始说话录音）：**不朗读任何语音**，直接播放你在音效设置里配置的“语音输入音效”（防止朗读声音抢占麦克风或被双击/手势音效盖掉）
    - 第二次触发（结束说话录音）：**不朗读“结束语音”**（播放手势确认音效；识别结果上屏后直接按读屏或语音回显朗读识别出的文字）

28. **智能整理**
    - 发起整理（异步处理中）：**`“正在智能整理”`**（若豆包在 120ms 内直接返回错误提示，如空框，则直接念工具栏提示不重复播报）
    - 工具栏弹出提示时：自动抓取并朗读豆包工具栏上的原话提示（例如 **`“请先输入内容再整理”`**、**`“表达清晰，无需整理”`**、整理超时/失败提示等）
    - 整理成功并替换了输入框文字：**`“整理完成，[整理后的文字]”`**
    - 当前版本不支持时：**`“当前豆包版本无法直接执行智能整理”`**

29. **执行发送**
    - 成功发送：模块不额外插话（由聊天应用自身或读屏反馈）
    - 发送失败：**`“当前豆包版本无法执行发送，请使用应用自己的发送按钮”`** 或 **`“这个输入框没有发送”`**

30. **发送并收起键盘**
    - 成功发送并收起键盘：如果开启了“键盘关闭时提示”，键盘收起时会按系统/模块提示播报；否则静默收起
    - 发送失败：**`“这个输入框没有发送”`**

31. **收起键盘**
    - 成功收起键盘：如果开启了“键盘关闭时提示”，收起时播报关闭提示
    - 收起失败：**`“键盘收不起来”`**

32. **临时关闭上半屏手势**
    - 成功临时关闭：**`“已暂时关闭全屏模式，下次展开自动恢复”`**
    - 当前本来就没开启时：**`“当前不是全屏模式”`**

33. **关闭上半屏手势**
    - 关闭时：**`“已关闭上半屏手势”`**
    - 开启时（如通过工具栏按钮再次点按开启）：**`“已开启上半屏手势”`**

### （七）不绑定动作（1 项）及通用失败提示的朗读

34. **未指定**
    - 当你在上半屏做了某个设为“未指定”的手势时：**`“[手势名称]没有设置动作”`**
      - 例如：**`“双指左滑没有设置动作”`**、**`“双指上滑没有设置动作”`**、**`“单指向左拖动没有设置动作”`**
- **通用不支持提示**：
  - 如果在密码框或特殊输入框中执行了无法读取/修改文本的编辑动作，会震动两下并朗读：**`“当前编辑框不支持”`**。
