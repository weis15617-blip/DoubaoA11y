# 桌面图标开关的来源与验收

功能参考维护者提供的 `DoubaoA11y-2.0.1-源码.zip` 中 activity-alias 和 `ui/Shortcut.kt` 的桌面入口方案。本次按主线设置页重新实现，直接读取 PackageManager，不沿用其 `hideShortcut` 偏好值，不引入跨进程设置、音效或全屏功能。源码包保留本项目 GPL-3.0 许可证，本次沿用；包内没有 Git 历史，贡献者姓名与原始提交待维护者补充，不虚构作者信息。

范围：

- 安装后桌面图标默认显示；“高级 → 显示桌面图标”只启用、禁用 LauncherAlias。
- SettingsActivity 本体保持启用，保留模块管理器设置入口；不向豆包广播本机图标状态。
- 每次打开高级页与返回前台时查询真实组件状态；设置失败后重新查询并回显。
- “全部恢复默认”先恢复桌面入口；失败则保留其他设置并提示，不假报恢复成功。

实机状态：未实机验证。记录手机、Android/ROM、桌面与模块管理器版本。

验收：

1. 从旧版覆盖安装后仅有一个桌面图标，名称、图标和打开设置页正常。
2. 关闭开关后桌面入口隐藏，当前设置页不被主动关闭；LSPosed/LSPatch 仍能打开 SettingsActivity。
3. 从模块管理器打开后开关反映真实状态；重新打开开关后图标恢复，重启应用、手机后保持。
4. 隐藏图标后执行“全部恢复默认”，图标与开关都恢复；开关状态不依赖豆包是否运行。
5. 组件变更或读取失败时，不假报成功；界面恢复真实状态，查询失败则禁用开关并提示。

编译与静态检查：使用 JDK 21.0.10、Android SDK platform 35 执行 ` .\gradlew.bat assembleRelease ` 成功（含 release lint 检查）；Git 差异空白检查通过，两份使用说明内容一致并保留 UTF-8 BOM。仅完成编译和静态检查，未实机验证。
