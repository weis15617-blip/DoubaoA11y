# 设置备份与恢复

当前整合版另提供完整 ZIP（含导入音频）及社区 ZIP 兼容恢复，JSON 继续可用。社区备份中完整短语格式的解释词不转换、不覆盖原词条；恢复确认展示跳过原因。相关更新和当前验证边界见《剩余功能验收》，下文保留此前 JSON 功能的交付记录。

开发分支 `codex/settings-backup` 基于整合测试提交 `23c9537`，保持前三项功能、版本、包名、权限和发布配置。此功能按现有设置表实现，没有引入社区包的 ZIP 音效恢复代码。

## 格式及行为

- 使用系统创建/打开文档界面，UTF-8 JSON，格式标记 `DoubaoA11y-settings`、版本 1，最大 1 MiB。
- 备份输入、候选、震动、手势、编辑轮盘、TTS 设置、自定义解释词和图标显示状态。
- 日志、调试、固定开关、使用须知与更新记录不导出；导入出现非白名单键时拒绝。
- 导入检查类型、整数可选范围、轮盘动作、自定义词条、文件大小和编码，全部通过才显示恢复确认。
- 备份未提供的字段保留；提供的自定义解释词整体替换。恢复确认显示图标状态及覆盖范围。
- 文件 I/O 与解析放在后台；恢复期间显示不可取消的进度对话框，保存失败回滚设置快照及原图标状态，回滚不完整明确提示。
- SharedPreferences 整份设置用一次 commit 保存，但组件状态和偏好存储属于两个系统操作，不能保证进程在任意瞬间被强杀时两者仍具备跨系统事务原子性。
- 完成后停止旧 TTS、刷新设置页、发送配置；豆包未运行时下一次启动通过现有 Provider 拉取。
- 不支持未知未来版本或社区 ZIP、音效备份，不导出输入内容或运行日志。

## 扩展与异常场景验收

1. 系统文件选择器导出、取消、选择已存在文件，以及只读/断开授权文件的提示。
2. 用自己的备份恢复后检查手势、TTS、自定义词和图标，确认日志/调试设置未改变。
3. 点击取消恢复不改任何配置；非法文件不改配置；保存失败时验证回滚提示。
4. 隐藏图标后从 LSPosed/LSPatch 打开设置，再恢复显示；更换手机后不存在的语音引擎能回退。
5. 横竖屏或退出页面时无窗口泄漏；恢复中进程被杀后的配置与图标需实际核对。
