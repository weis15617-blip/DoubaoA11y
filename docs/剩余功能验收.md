# 独立版本剩余功能验收

范围：工具栏全屏/半屏切换、豆包设置内入口、音效与自定义音频、独立 TTS 输入/删除/语音结果回声、整段标点名称朗读、保益与点明接口、无拼音候选回退。解释词库、词条及其编辑格式保持原样。

## 行为与入口

- 输入方式：新增“工具栏显示全屏与半屏切换”，默认开启。工具栏按钮显示将要切换的模式，点击保存输入方式；豆包定制工具栏中也可添加或移除该按钮，不改变输入方式。标准输入切到全屏后，再切回时使用抬手半屏。
- 豆包设置：首页上方新增“豆包无障碍模块设置”。使用普通布局包装，不向 RecyclerView 添加子项；打开失败提示从模块管理器进入。
- 音效：首页“音效”，总开关默认关闭，六类事件可分别试听、导入和恢复。内置六个音频来自用户提供的源码 ZIP，用户已确认自制并授权纳入，来源见《音频来源记录》。每个操作可从六种声音中选择，内置和导入音频统一跟随媒体或无障碍音量通道。导入使用系统文件选择器，限制 5 MB、5 秒且含音轨；先校验临时文件再替换。音频留在模块私有目录；JSON 设置备份不包含音频文件，另提供完整 ZIP 备份导入音频，“全部恢复默认”保留音频文件。
- 独立 TTS：关闭“使用屏幕阅读器播报”后，可分别开启输入、删除、语音最终结果回声，以及标点名称朗读。新增回声和标点选项默认关闭。密码框不补读正文；编辑器不提供可确认正文时保守跳过回声。
- 快速输入：新增“保益、点明全屏直接触摸接口”，默认关闭。只在相应读屏和全屏键盘活动时请求；菜单、收起、锁屏、退出全屏或换读屏时恢复。发送成功不能证明读屏接受；实际触摸/悬停事件决定后续路径。恢复失败保留恢复信息，输入法重新初始化时再尝试恢复。进程被强制终止时无法保证立即恢复，可能需要手动打开触摸浏览。天坦与解说原有区域接口保留。
- 无拼音候选：根据输入来源及候选会话识别手写、九键等候选，不将任意联想或剪贴板文字自动当成正在组字的候选；保留延迟取消和光标移动保护。

## 人工验收

1. 模块开启、关闭，读屏开启、关闭；抬手、标准、全屏三种输入模式。工具栏按钮应出现/隐藏正确，切换后重启输入法仍保存。
2. 豆包设置进出、旋转、进入子页面再返回；入口不重复，不遮挡原控件。隐藏模块桌面图标后入口仍能打开模块。
3. 音效关闭不响；开启后摸键、滑候选、手势成功/失败、双击/编辑选项、开始语音。关闭触摸震动后音效仍有效。试听六类，导入短音频并恢复；取消、空文件、非音频、过大、过长文件均不覆盖已有音效。
4. 输入回声：连续输入两个相同字、选择候选、输入符号、组合文本确认；每次实际写入只读一次。删除选区、连续删除、删除 emoji；密码框不补读内容，未成功操作不读。开启读屏播报后不叠加模块 TTS 回声。
5. 语音回声：最终上屏只读一次，中间结果、撤回不读；连续两次说相同内容分别朗读。标点名称打开/关闭后分别朗读含逗号、句号、括号与换行的固定测试句。
6. 各读屏分别实测。保益、点明接口开关关闭时应保留原操作；开启后检查菜单、收起、锁屏、切读屏、模块关闭后的恢复；不响应或受后台服务限制时检查降级路径。额外记录读屏版本、豆包版本、手机和配置。
7. 九键、手写有候选但没有拼音时检查首候选朗读、左右切换和上屏；普通联想、移动光标、切输入框、候选清空和键盘收起后不残留旧会话。
